# Выгрузка на Яндекс Игры

## 1. Один раз
```bash
npm i @fontsource/russo-one
npm i -D archiver
```

В `package.json` → `scripts` добавь:
```json
"build:yandex": "tsc && vite build --mode yandex",
"pack:yandex": "npm run build:yandex && node scripts/pack-yandex.mjs"
```

## 2. Сборка архива
```bash
npm run pack:yandex
```
Получится `yandex-build.zip`: `index.html` лежит в корне архива, SDK (`/sdk.js`) подключён
автоматически только в этой сборке. Внешних запросов нет: шрифт и все текстуры внутри бандла.

## 3. Консоль разработчика Яндекс Игр
1. Создай игру → загрузи `yandex-build.zip` как HTML5-архив.
2. Ориентация: «любая» (игра адаптивна под портрет и ландшафт).
3. Языки: русский и английский (игра берёт язык из SDK; для остальных — английский).
4. Загрузи иконку, обложку и скриншоты (актуальные размеры и требования смотри в консоли).
5. Отправь черновик и проверь по чек-листу ниже.

## 4. Что уже сделано в коде
- SDK: `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop` при игре/паузе/рекламе.
- Межстраничная реклама раз в 3 минуты активной игры, с обратным отсчётом 3 сек перед показом
  (`systems/AdSystem.ts`). Отсчёт сбрасывается после любой рекламы, на время рекламы звук выключается.
- Rewarded-реклама: ×2 аура на 2 минуты и перерождение без сброса.
- Облачные сохранения (`player.getData/setData`) + localStorage; при загрузке берётся более свежее.
- Язык из `ysdk.environment.i18n.lang`, иначе язык браузера. Русский — полный перевод.
- Пауза по `game_api_pause` / `game_api_resume`; Phaser сам ставит звук на паузу при сворачивании вкладки.
- Отключены контекстное меню, зум жестами и выделение текста.

## 5. Чек-лист перед модерацией
- [ ] Игра запускается из архива без ошибок в консоли браузера (F12).
- [ ] Звук выключается при сворачивании вкладки и во время рекламы.
- [ ] Реклама не появляется сразу при старте, только после ~3 минут игры.
- [ ] Rewarded-кнопки работают и дают награду только после досмотра.
- [ ] Сохранение не теряется после перезагрузки страницы.
- [ ] Проверено на телефоне в портрете и ландшафте.
- [ ] В игре нет ссылок на сторонние сайты и упоминаний других площадок.

## 6. Как проверить рекламу локально
- В `npm run dev` rewarded-реклама эмулируется (0,6 сек).
- Межстраничную можно эмулировать: открой `http://localhost:5173/?testads`.
- Реальную рекламу проверяй в черновике игры в консоли Яндекса.
